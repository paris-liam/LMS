Shopify theme customizer reference

Custom sections & blocks

Everything below is a section or block built specifically for the Little Movie Store site — not a stock Shopify feature. This is a reference for editing them in the theme editor at Online Store → Themes → Customize. It doesn't cover the standard Shopify sections (header, footer, product pages, etc.) already documented elsewhere.

7 home page sections 1 password page section 1 reusable block

Finding these in the editor

In the customizer, click Add section where you want one to go, then search the name (e.g. “LMS hero”). Every section here already has a ready-made preset, so adding it fills in sensible starting content — you're not starting from a blank section.

Where: Password page (the site's current front door)
This section has no editable settings in the customizer. Every piece of its text, the animation, and the Instagram link are written directly into the section's code. To change any wording or behavior here, a developer needs to edit it in the theme files — it can't be done from the customizer.
