Each row opens that batch's own review-picker.html in a new tab (a picker page can't embed another origin's page inline, so this is a launcher, not a single merged picker). Pick posters, click Export picks in that tab — it downloads that batch's own tmdb-picks.json. Move the download into the matching out-product_export_N/ folder, then run:

python3 formatting-scripts/apply_picks.py catalogue-batches/out-product_export_N/tmdb-picks.json catalogue-batches/out-product_export_N/upload.csv

This page was opened directly as a file:// URL. Each picker page's progress lives in its browser's localStorage, which is scoped to a page's own origin — under file://, that can be inconsistent across files depending on the browser, so the progress bars below may read 0 even after you've made picks. Serve this folder over a local static server (e.g. python3 -m http.server from the repo root) and open this page through http://localhost:<port>/... for reliable progress.
