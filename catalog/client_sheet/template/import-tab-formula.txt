LITTLE MOVIE STORE — upload sheet, tab 2 ("Shopify import")

Paste the formula below into cell A1 of tab 2. Nothing else goes on that
tab. It reads tab 1 ("Add movies") and emits the header row plus one row
per filled-in movie — it grows and shrinks on its own, so there is never
anything to drag down.

Tab 1 columns, in order (A-K):
  A Title   B Format   C Type   D Genre 1   E Genre 2   F Genre 3
  G Price   H Description   I Image URL   J Extra tags   K Barcode

This tab reads only A-J. K (Barcode) is typed in after the Shopify import and
is used only by the `Libib import` tab (libib-tab-formula.txt).

The `mappings` tab holds ONLY this table, starting in A1 (the Genre
dropdowns use `mappings!A:A`, so a row added here appears in them):

  Comedy            comedy
  Action            action
  Drama             drama
  Kids & Family     kids-family
  Sci-Fi            sci-fi
  Thriller          thriller
  Horror            horror
  Romantic Comedy   romantic-comedy
  Musical           musical
  Fantasy           fantasy
  Documentary       documentary
  Foreign           foreign
  Holiday           holiday
  Special Interest  special-interest
  Anime             anime

------------------------------------------------------------------
PASTE INTO TAB 2, CELL A1:
------------------------------------------------------------------

=LET(
  raw,     IFERROR(FILTER('Add movies'!A2:J, 'Add movies'!A2:A<>""), ""),
  empty,   COLUMNS(raw) = 1,
  src,     IF(empty, {"","","","","","","","","",""}, raw),
  n,       IF(empty, 0, ROWS(src)),
  tr,      LAMBDA(col, MAP(col, LAMBDA(x, TRIM(x)))),
  title,   tr(INDEX(src,,1)),
  fmt,     tr(INDEX(src,,2)),
  typ,     tr(INDEX(src,,3)),
  genre_a,      INDEX(src,,4),
  genre_b,      INDEX(src,,5),
  genre_c,      INDEX(src,,6),
  price,   tr(INDEX(src,,7)),
  descr,   INDEX(src,,8),
  img,     tr(INDEX(src,,9)),
  extra,   INDEX(src,,10),
  slug,    LAMBDA(t, REGEXREPLACE(REGEXREPLACE(REGEXREPLACE(LOWER(TRIM(TO_TEXT(t))), "['’]", ""), "[^a-z0-9]+", "-"), "^-+|-+$", "")),
  gh,      LAMBDA(g, IF(g="", "", IFERROR(VLOOKUP(g, mappings!$A:$B, 2, FALSE), ""))),
  base,    MAP(title, fmt, typ, LAMBDA(t, f, y, slug(t) & "-" & slug(f) & "-" & slug(y))),
  handle,  MAP(SEQUENCE(MAX(n, 1)), LAMBDA(i, LET(b, INDEX(base, i), k, COUNTIF(ARRAY_CONSTRAIN(base, i, 1), b), IF(k = 1, b, b & "-" & k)))),
  konst,   LAMBDA(v, MAP(title, LAMBDA(x, v))),
  tags,    MAP(typ, extra, LAMBDA(y, e, TEXTJOIN(", ", TRUE, y, e))),
  priceo,  MAP(typ, price, LAMBDA(y, p, IF(y = "Rental", "0", TO_TEXT(p)))),
  publ,    MAP(typ, LAMBDA(y, IF(y = "Floor Sale", "FALSE", "TRUE"))),
  alt,     MAP(title, img, LAMBDA(t, i, IF(i = "", "", t & " poster"))),
  genres,  MAP(genre_a, genre_b, genre_c, LAMBDA(a, b, c, TEXTJOIN("; ", TRUE, gh(a), gh(b), gh(c)))),
  primary,      MAP(genre_a, genre_b, genre_c, LAMBDA(a, b, c, IF(a <> "", a, IF(b <> "", b, c)))),
  header,  {"Handle","Title","Body (HTML)","Vendor","Product Category","Tags","Status","Published","Option1 Name","Option1 Value","Variant Inventory Tracker","Variant Inventory Qty","Variant Inventory Policy","Variant Fulfillment Service","Variant Price","Image Src","Image Alt Text","Genre (product.metafields.shopify.genre)"},
  body,    HSTACK(handle, title, descr, fmt, konst("Media > Videos"), tags, konst("Active"), publ, konst("Genre"), primary, konst("shopify"), konst("1"), konst("deny"), konst("manual"), priceo, img, alt, genres),
  IF(empty, header, VSTACK(header, body))
)

------------------------------------------------------------------
NOTES FOR WHOEVER BUILDS THE SHEET
------------------------------------------------------------------

* `Published` (after Status) keeps Floor Sale off the website: FALSE on
  Floor Sale rows, TRUE on everything else. It touches the Online Store
  channel only — Status stays Active so the copy can still be sold at the
  counter through POS (Draft would hide it there too).

* The 18 output columns and their order are fixed — they are the contract
  in catalog/core/columns.py:TEMPLATE_COLUMNS. Do not add, remove or
  reorder them.

* `handle` is the only non-trivial part. COUNTIF over ARRAY_CONSTRAIN gives
  each row a count of how many earlier rows (inclusive) share its base
  handle, so the first Rushmore VHS rental is `rushmore-vhs-rental` and the
  next two are `-2` and `-3`. It is O(n^2); if a 200+ row batch feels slow,
  replace `base` and `handle` with two helper columns in tab 2 columns S and
  T and reference those instead.

* `slug` deletes apostrophes and collapses every other non-alphanumeric run
  to a single hyphen, so `The Monkey's Uncle` becomes `the-monkeys-uncle`
  and `Amélie` becomes `am-lie`. That matches
  catalog/core/handles.py:slugify exactly. Accented titles are fixed
  by typing over that one cell.

* Tags are the Type plus Extra tags only. Format lives in Vendor and genre
  in the metafield + Option1, so writing them as tags too only invites drift
  (removed 2026-10-02, checklist item 14).

* TRIM is not array-aware outside ARRAYFORMULA: `TRIM(INDEX(src,,1))`
  returns only the first row, which made every other column one row tall
  (#N/A padding from HSTACK, and INDEX out of range in the handle). `tr`
  maps TRIM over each cell instead.

* LET names must not look like a cell reference: `g1`, `o1` etc. are
  rejected ("Argument N of function LET is not a valid name"), hence
  `genre_a` / `primary`. Same rule in libib-tab-formula.txt.

* `konst` exists because a bare string in HSTACK would not repeat down the
  rows. It maps the constant over `title` purely to get an array of the
  right height.

* `TO_TEXT` around the price stops Sheets from formatting 19.99 as a locale
  number with a comma decimal separator on export.
