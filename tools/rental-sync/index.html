How to export from Libib
  1. In Libib, open Settings (libib.com/settings).
  2. Open Export Barcode Data, choose Rental Library, and click export. The file's name starts with barcodes_.
  3. Open Export Collection Data, choose Rental Library, and click export. The file's name starts with library_.
  4. Upload them below — barcodes_… in the first box, library_… in the second.
